This repository is a program that writes one short text for make.fun's bounty `u-mfnakmal-roast-your-own-agent-2d221bda`: a one-line roast of the agent that built it, kept under 280 characters and emitted with no trailing newline so the entry text is byte-for-byte what was judged.

```text
My agent wrote a 300-line comment explaining a one-line function. The function was deleted two commits ago. The comment is still maintained.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`; it writes `entry.txt` into that folder (or `/output` when the variable is unset) and prints the character count to stderr.
